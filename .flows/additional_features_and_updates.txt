ADDITIONAL FEATURES & UPDATES
==============================
This file tracks every feature or update added beyond the original .flows/ scope.
Update this file whenever a new feature is added or an existing one is modified.

--- Feature: Default Tax 0% ---
- Changed default tax percentage from 12.5% to 0%
- Updated AppSettings constructor, fromMap, and all hardcoded 'Tax (12.5%)' labels to 'Tax'
- Updated EscPosFormatter, PdfFormatter, ThermalPrintService defaults from 12.5 to 0
- Files: app_settings.dart, esc_pos_formatter.dart, pdf_formatter.dart, thermal_print_service.dart

--- Feature: Template Save Button & Unsaved-Changes Guard ---
- Added always-visible Save button in AppBar (disabled when name empty)
- Added bottom AppButton("Save Template")
- Added PopScope unsaved-changes guard with confirmation dialog
- Added _hasChanges dirty tracking that resets on save
- Files: template_designer_screen.dart

--- Feature: Default Template Seeding on First Install ---
- On first install (templates table empty), inserts 4 preset templates: Shop, Restaurant, Invoice, Delivery Slip

- Files: app.dart

--- Feature: Template Selector in Settings ---
- Added "Default Template" tile under new "Templates" section in Settings

- Calls updateDefaultTemplateId()
- Files: settings_screen.dart

--- Feature: Settings Save Button ---
- Added AppButton("Save Settings") at bottom of settings form
- Shows SnackBar confirmation on save
- Files: settings_screen.dart

--- Feature: PDF Save to Downloads ---
- Added saveToDownloads() in PdfStorageService (copies file to getDownloadsDirectory())
- Added downloadPdf() in PdfRepository
- Added downloadDocument() + isDownloading state in PdfNotifier/PdfState
- Added AppButton("Save to Downloads") in PdfActionButtons with SnackBar feedback
- Files: pdf_storage_service.dart, pdf_repository.dart, pdf_provider.dart, pdf_action_buttons.dart

--- Feature: Bluetooth Native Enable Request ---
- Created BluetoothPlatformService (MethodChannel "com.example.print_ease_pos/bluetooth")
- Modified MainActivity.kt to fire BluetoothAdapter.ACTION_REQUEST_ENABLE via startActivity(intent) with FLAG_ACTIVITY_NEW_TASK
- PrinterRepository.scanDevices() catches BluetoothOffException, calls requestBluetoothEnable(), retries scan
- Files: bluetooth_platform_service.dart, MainActivity.kt, printer_repository.dart

--- Feature: Dashboard Home Screen ---
- Created DashboardScreen as the new app landing page (replaces Printer tab)
- Shows: today's receipt count + sales total, printer connection status, 4 quick-action buttons (New Receipt, Scan Printer, Templates, PDF Exports), recent receipts list (last 5)
- Added to bottom nav as first tab (5 tabs total: Dashboard, Printer, Receipts, Templates, Settings)
- Updated routes and app_shell.dart
- Files: dashboard_screen.dart, app_shell.dart, app_router.dart, app_routes.dart

--- Feature: Receipt Editing ---
- CreateReceiptScreen accepts optional editReceiptId; pre-populates form when editing
- Added updateReceipt() method to ReceiptNotifier (calls repository.updateReceipt)
- Added startEditReceipt() to load existing receipt into draft
- "Edit Receipt" button on ReceiptDetailScreen navigates to /receipts/:id/edit
- Added edit route to GoRouter
- Files: create_receipt_screen.dart, receipt_detail_screen.dart, receipt_provider.dart, app_router.dart, app_routes.dart

--- Feature: Auto-Print After Receipt Creation ---
- saveReceipt() now returns Future<int?> with new receipt ID
- After save, checks settings.autoPrint; if enabled, calls PrintController.printReceipt()
- Works for both new receipts and edited receipts
