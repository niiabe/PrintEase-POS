# Simple Thermal POS Printer App — Suggestion + Implementation File

## App Overview

A lightweight Flutter-based thermal POS printer app that:

* Connects to Bluetooth/Wi-Fi thermal printers
* Lets users design receipt layouts visually
* Saves receipts locally on the device
* Exports receipts as PDF
* Prints directly to POS printers
* Works offline
* Requires no login/account
* Supports multiple POS paper sizes

# Receipt Model

```dart
class ReceiptModel {
  final int? id;
  final String receiptNo;
  final String customerName;
  final String items;
  final double total;
  final String pdfPath;
  final DateTime createdAt;

  ReceiptModel({
    this.id,
    required this.receiptNo,
    required this.customerName,
    required this.items,
    required this.total,
    required this.pdfPath,
    required this.createdAt,
  });
}
```

# Important Technical Recommendations

## 1. Start With Bluetooth Only

Simpler MVP.

---

## 2. Use ESC/POS Printers Only

Best compatibility.

---

## 3. Use Local Storage First

Avoid backend complexity.

---

## 4. Keep Receipt Builder Simple Initially

Settings-driven layout first.
